# 迭代需求文档

## 文档信息

- **迭代版本**：V2.2
- **需求类型**：核心功能迭代 - 后端 API 实现
- **涉及模块**：认证模块、用户模块、AI 对话模块、菜单权限模块
- **后端技术栈**：Node.js + Express + SQLite + Redis
- **项目路径**：D:\wybD\Codes\demos\backend\vue-nodejs-demo

---

## 一、需求背景

将前端项目 vue-demo 的所有 Mock 数据替换为真实的后端 API，实现完整的业务逻辑闭环。后端采用轻量级技术栈（Express + SQLite），便于本地开发和调试。

### 1.1 技术选型理由

| 技术 | 选型 | 理由 |
|------|------|------|
| Web 框架 | Express.js | 轻量、简洁、社区成熟 |
| 数据库 | SQLite (better-sqlite3) | 零配置、文件级存储、适合本地开发 |
| 缓存 | Redis | 辅助缓存 token、Session、热点数据 |
| 流式输出 | SSE (Server-Sent Events) | 与前端 fetch + ReadableStream 配合 |
| 加密 | AES-256-CBC | 对称加密，密码/敏感字段传输加密 |

## 三、数据库设计

### 3.1 SQLite 表结构

```sql
-- 用户表
CREATE TABLE users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  username TEXT UNIQUE NOT NULL,
  password TEXT NOT NULL,  -- BCrypt 加密
  nickname TEXT NOT NULL,
  avatar TEXT,
  email TEXT,
  phone TEXT,
  role TEXT DEFAULT 'user',  -- admin / user
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 对话会话表
CREATE TABLE chat_sessions (
  id TEXT PRIMARY KEY,
  user_id INTEGER NOT NULL,
  title TEXT NOT NULL,
  context_config TEXT,  -- JSON: maxTokens, maxMessages, strategy
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (user_id) REFERENCES users(id)
);

-- 对话消息表
CREATE TABLE chat_messages (
  id TEXT PRIMARY KEY,
  session_id TEXT NOT NULL,
  role TEXT NOT NULL,  -- user / assistant
  content TEXT NOT NULL,
  tokens INTEGER DEFAULT 0,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (session_id) REFERENCES chat_sessions(id)
);

-- 用户上下文配置表
CREATE TABLE user_context_config (
  user_id INTEGER PRIMARY KEY,
  config TEXT NOT NULL,  -- JSON
  FOREIGN KEY (user_id) REFERENCES users(id)
);

-- 菜单表
CREATE TABLE menus (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  title TEXT NOT NULL,
  icon TEXT,
  path TEXT,
  parent_id TEXT,
  sort INTEGER DEFAULT 0,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 3.2 索引

```sql
CREATE INDEX idx_chat_sessions_user ON chat_sessions(user_id);
CREATE INDEX idx_chat_messages_session ON chat_messages(session_id);
CREATE INDEX idx_chat_messages_created ON chat_messages(created_at);
```

## 四、Redis 缓存设计

### 4.1 Key 命名规范

| Key 格式 | 说明 | TTL |
|----------|------|-----|
| `token:{userId}` | 用户 JWT token | 7 天 |
| `user:profile:{userId}` | 用户信息缓存 | 1 小时 |
| `chat:session:{sessionId}` | 当前对话上下文 | 30 分钟 |
| `menu:list:{userId}` | 用户菜单缓存 | 1 小时 |

### 4.2 缓存策略

- **Token**：登录时写入 Redis，登出时删除
- **用户信息**：读取时写入缓存，更新时删除缓存
- **对话上下文**：SSE 交互时更新 TTL
- **菜单列表**：按用户角色缓存

## 五、非功能需求

### 5.1 性能

- SSE 流式响应延迟 < 100ms（Mock 模式下即时返回）
- 数据库查询 < 50ms
- Redis 缓存命中 > 90%

### 5.2 安全性

- 密码 BCrypt 加密存储
- 敏感字段 AES 加密传输
- JWT token 7 天过期
- 接口请求频率限制

### 5.3 开发便利性

- SQLite 数据库文件存储在 `data/vue-demo.db`，可直接用 SQLiteStudio 打开查看
- 支持 `npm run seed` 初始化测试数据
- 支持 `npm run dev` 热重载开发
