# 迭代需求文档
## 文档信息
- **迭代版本**：V2.0
- **需求类型**：核心功能迭代
- **涉及模块**：AI 对话模块、流式通信、Markdown 渲染
- **后端依赖**：无（模拟 SSE 流式响应）

---

## 一、需求背景
实现 AI 对话核心能力，包括基于 SSE（Server-Sent Events）的流式文本输出、对话消息管理、Markdown 格式渲染。这是整个项目 AI 能力的核心基础。本次迭代新增单条对话消息删除能力，完善单条消息操作能力。

---

## 二、需求详情

### 1. SSE 流式对话
1. **功能范围**
   - 用户发送消息后，AI 逐字返回生成内容
   - 实现"打字机"效果的流式渲染
   - 支持中断生成（停止按钮）
2. **技术实现**
   - 使用 `fetch` + `ReadableStream` 读取流式数据
   - 逐块（chunk）解析 SSE 格式数据
   - 实时更新对话内容
   - 实现 AbortController 中断请求
3. **Mock 约束**
   - 模拟流式响应：预置回答文本，按 chunk 逐步返回
   - 模拟延迟与网络抖动

### 2. 对话消息管理
1. **功能范围**
   - 对话列表展示：用户消息、AI 回复、系统消息
   - 新建对话、切换对话、删除对话
   - 对话状态管理（发送中、流式中、完成、错误）
   - 单条消息操作：消息复制、重新生成、**单条消息删除**
2. **实现要求**
   - 使用 Pinia/Vuex 管理对话状态
   - 每条消息包含 id、角色、内容、状态、时间戳
   - 支持消息复制、重新生成
   - 【新增】单条消息删除能力：
     1. UI 布局：在每条消息底部/悬浮操作栏，复制、重新生成按钮旁新增**删除**操作按钮；
     2. 交互逻辑：点击删除按钮，弹出二次确认弹窗，确认后移除当前这条对话消息，仅删除本条，不影响同对话内其他消息；
     3. 状态处理：删除消息后更新 store 对话消息列表，页面实时刷新；
     4. 边界约束：流式生成中未完成的 AI 消息也支持删除，删除时同步终止当前 SSE 请求；
     5. 数据处理：仅移除当前消息对象，不删除整个对话会话。

### 3. Markdown 渲染
1. **功能范围**
   - AI 返回的 Markdown 内容实时渲染
   - 支持标题、列表、代码块、表格、链接等
   - 代码块语法高亮
2. **实现要求**
   - 使用 markdown-it 或 marked 解析 Markdown
   - 代码块使用 highlight.js 语法高亮
   - 流式渲染时处理不完整的标签（避免截断问题）

---

## 三、非功能需求
- **性能**：长文本流式渲染时避免页面卡顿；单条消息删除无页面闪烁、无阻塞
- **体验**：打字机效果流畅，中断响应及时；删除二次确认弹窗简洁，操作反馈清晰
- **兼容性**：Markdown 渲染结果正确，代码高亮正常；用户消息、AI 消息均展示删除按钮

---

## 四、验收标准
1. 发送消息后 AI 能逐字返回流式内容
2. 支持中途停止生成
3. Markdown 内容正确渲染，代码块有语法高亮
4. 对话列表管理功能正常（新建、切换、删除）
5. 全部使用 Mock 模拟流式响应
6. 【新增验收项】
   - 每条用户、AI 消息操作栏复制、重新生成旁可见删除按钮；
   - 点击删除弹出确认弹窗，确认后仅删除本条消息，其他对话消息保留；
   - 流式加载中的 AI 消息点击删除，可终止生成并清空本条内容；
   - 删除后对话列表实时更新，无数据错乱。

---

## 五、输出物
- AI 对话页面（views/chat/index.vue）
- SSE 流式客户端封装（utils/sse-client.ts）
- 对话状态管理（store/modules/chat.ts）
- Markdown 渲染组件
- Mock 流式响应逻辑
- 依赖：markdown-it、highlight.js
- 新增输出逻辑：
  1. 消息操作栏 UI 组件新增删除按钮；

  3. 删除确认弹窗通用组件/内部弹窗逻辑；
  4. 删除未完成流式消息时终止 SSE 的联动逻辑。
