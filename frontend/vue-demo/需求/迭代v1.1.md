# 迭代需求文档
## 文档信息
- **迭代版本**：V1.1
- **需求类型**：功能迭代 / 体验优化
- **涉及模块**：用户中心、个人信息管理、密码修改
- **后端依赖**：无（继续使用 Mock 数据）

---

## 一、需求背景
完善用户个人信息管理能力，为用户提供个人信息查看与修改、密码修改、头像上传等功能，为后续 AI 功能中的用户偏好设置打下基础。

---

## 二、需求详情

### 1. 用户信息展示与编辑
1. **功能范围**
   - 用户基本信息展示：头像、昵称、邮箱、手机号、角色
   - 支持编辑昵称、邮箱、手机号
   - 表单校验与提交
2. **实现要求**
   - 用户信息从 Store 或 Mock 接口获取
   - 编辑后实时更新 Store 与本地缓存
   - 表单校验使用 Element Plus 表单组件

### 2. 密码修改
1. **功能范围**
   - 输入旧密码、新密码、确认新密码
   - 密码强度校验（长度、字符类型）
   - 旧密码正确性校验
2. **实现要求**
   - 密码使用加密传输（复用 V1.0 加密工具）
   - 修改成功后提示重新登录或自动刷新 token

### 3. 头像上传
1. **功能范围**
   - 支持点击/拖拽上传头像
   - 图片预览、裁剪
   - 上传进度提示
2. **实现要求**
   - 使用 Element Plus Upload 组件
   - 图片限制格式与大小
   - Mock 环境下模拟上传成功

### 4. 换肤功能
1. **功能范围**
   - 提供内置主题切换：默认（亮色）、深色、蓝色
   - 主题偏好持久化到 localStorage
   - 切换主题后全局实时生效（侧边栏、头部、内容区、Element Plus 组件）
2. **实现要求**
   - 使用 CSS 变量（CSS Custom Properties）管理主题色
   - 主题配置集中管理（`src/styles/themes/`）
   - 切换入口：右侧头部提供主题切换按钮（图标或下拉菜单）
   - 切换主题时同步更新 Element Plus 的 CSS 变量（`--el-color-primary` 等）
   - 页面刷新后自动恢复上次选择的主题

---

## 三、非功能需求
- **安全性**：密码修改需验证旧密码，敏感操作需二次确认
- **兼容性**：图片上传支持主流格式（jpg/png/gif）
- **可维护性**：表单校验规则复用，错误提示统一

---

## 四、验收标准
1. 用户信息可正常查看与编辑
2. 密码修改流程完整，校验正确
3. 头像上传功能可用（Mock 模拟）
4. 所有数据使用 Mock，无真实接口调用

---

## 五、输出物
- 用户中心页面（views/profile/index.vue）
- 密码修改弹窗/页面
- 头像上传组件
- Mock 用户信息与密码修改逻辑
