# 迭代需求文档
## 文档信息
- **迭代版本**：V1.0
- **需求类型**：功能迭代 / 安全优化 / 体验优化
- **涉及模块**：登录模块、全局国际化、请求加密
- **后端依赖**：无（登录逻辑继续使用 Mock 数据）

---

## 一、需求背景
为完善系统登录流程、提升接口传输安全性，并支持多语言使用场景，本次迭代对 SSO 登录相关逻辑进行补充，新增请求加密机制与国际化能力。

---

## 二、需求详情

### 1. 补全 SSO 登录相关前端逻辑
1. **功能范围**
   - 完善 SSO 登录页面结构、表单交互、状态提示
2. **后端约束**
   - 登录接口、返回字段、权限结构**继续使用现有 Mock 数据**
   - 不开发真实后端接口、不接入真实认证服务

### 2. 登录接口用户信息加密传输
1. **加密范围**
   - 登录接口请求体中**敏感字段**：账号、密码、token 等
2. **加密方式**
   - 建议使用 **AES** 对称加密或 **RSA** 非对称加密
   - 密码等敏感信息禁止明文传输
3. **实现要求**
   - 前端统一封装加密工具方法，登录请求自动加密
   - 与 Mock 规则对齐，Mock 层可正常解密/识别
   - 网络请求中不可在控制台/日志中暴露原始明文

### 3. 项目国际化支持（中/英）
1. **支持语言**
   - 简体中文（默认）
   - English
2. **国际化范围**
   - 登录页：标题、提示语、按钮、校验文案、错误信息
   - 全局通用文本：按钮、弹窗、加载提示、菜单名称
   - 业务提示信息与 Toast 信息
3. **实现要求**
   - 使用 i18n 方案（如 vue-i18n / react-i18next）
   - 语言配置文件抽离为独立 JSON/JS 文件
   - 支持语言切换（若有切换入口）或根据浏览器语言自动识别
   - 切换语言后页面无刷新实时更新

---

## 三、非功能需求
- **安全性**：敏感信息必须加密，不允许明文传输
- **兼容性**：主流现代浏览器正常展示与切换语言
- **可维护性**：国际化文本统一维护，加密工具统一封装

---

## 四、验收标准
1. SSO 登录前端流程完整可用、跳转正常
2. 登录接口查看 Request Payload 无明文密码/敏感信息
3. 系统可正常切换中/英文，所有文案正确显示，无缺失、乱码
4. 后端逻辑仍为 Mock 数据，无真实接口调用

---

## 五、输出物
- 国际化语言配置文件
- 加密工具类/工具函数
- SSO 登录相关页面及逻辑代码
