# 迭代需求文档
## 文档信息
- **迭代版本**：V2.2
- **需求类型**：架构扩展
- **涉及模块**：Node.js BFF 代理层、API 网关、缓存策略
- **后端依赖**：无（模拟 AI 模型 API）

---

## 一、需求背景
构建 Node.js BFF（Backend For Frontend）薄代理层，将 AI 模型 API 的密钥隐藏在服务端，同时添加 LRU 缓存降低调用成本，为后续真实 AI 接口接入做准备。

---

## 二、需求详情

### 1. BFF 代理服务
1. **功能范围**
   - Node.js 中间层（Express/Koa）
   - 代理转发 AI 模型 API 请求
   - API 密钥管理（环境变量存储，不在前端暴露）
2. **实现要求**
   - 提供与前端相同的 API 接口路径
   - 请求转发时添加认证头
   - 错误处理与日志记录

### 2. LRU 缓存机制
1. **功能范围**
   - 相同请求直接返回历史结果，不调用模型 API
   - 缓存键基于请求内容（prompt + 模型参数）
   - 支持缓存过期时间、最大缓存条目数
2. **实现要求**
   - 使用 Node 内存 LRU 缓存或 Redis
   - 缓存命中时返回历史响应，添加缓存命中头信息
   - 支持缓存清理接口

### 3. 前端对接 BFF
1. **功能范围**
   - 前端 API 请求指向 BFF 服务
   - 开发环境支持代理配置
   - 缓存命中状态展示
2. **实现要求**
   - 请求拦截器自动附加 token
   - 响应拦截器处理 BFF 返回格式
   - 开发模式可切换 Mock/BFF

---

## 三、非功能需求
- **安全性**：API 密钥绝不暴露到前端代码或日志中
- **性能**：缓存命中时响应延迟 < 50ms
- **成本**：缓存策略有效降低模型调用次数

---

## 四、验收标准
1. BFF 服务正常代理 AI 请求
2. 相同请求第二次命中缓存
3. 前端控制台不暴露 API 密钥
4. 开发环境可切换 Mock/BFF 模式

---

## 五、输出物
- Node.js BFF 服务（server/ 目录）
- LRU 缓存中间件
- API 代理路由
- 前端对接适配层
- 依赖：express/koa、lru-cache
