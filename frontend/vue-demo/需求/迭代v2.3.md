## 一、需求背景

### 1.1 什么是 SSO 单点登录

SSO（Single Sign-On）单点登录是一种 authentication（身份认证）机制，用户只需在一个系统登录一次，就可以访问所有信任该认证中心的其他系统。

**没有 SSO**：
```
用户访问 系统A → 登录 → 访问 系统B → 再次登录 → 访问 系统C → 又要登录
```

**有 SSO**：
```
用户访问 系统A → 跳转 SSO 登录 → 登录成功 → 重定向回 系统A（已登录）
访问 系统B → 无需登录（SSO Cookie 有效）→ 直接进入
访问 系统C → 无需登录 → 直接进入
```

### 1.2 本次迭代目标

构建一个独立的 **SSO 鉴权中心**，包含：
1. SSO 后端服务：管理用户账户、登录逻辑、Token 颁发
2. SSO 前端门户：统一的登录页面
3. Client Demo：演示如何接入 SSO（基于 vue-demo 改造）

  nickname TEXT,

  redirect_uri TEXT NOT NULL,       -- 回调地址

  status INTEGER DEFAULT 1,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP

-- Token 表
CREATE TABLE tokens (
  token TEXT PRIMARY KEY,
  user_id INTEGER NOT NULL,
  app_id TEXT NOT NULL,
  expires_at DATETIME NOT NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,

#### 2.1.3 SSO 授权流程

**标准 OAuth 2.0 Authorization Code 流程（简化版）**：

```
1. 用户访问 Client App（如 vue-demo）
   → Client App 发现用户未登录，跳转到 SSO
   → URL: http://sso.local/authorize?app_id=xxx&redirect_uri=xxx&state=xxx

2. SSO 显示统一登录页面
   → 用户输入用户名密码

3. 登录成功，SSO 生成临时 code
   → 重定向回 Client App
   → URL: http://vue-demo.com/callback?code=xxx&state=xxx

4. Client App 用 code 换取 token
   → POST http://sso.local/token
   → body: { app_id, app_secret, code }

5. SSO 返回 token
   → Client App 用 token 获取用户信息

6. 后续请求，Client App 验证 token
   → POST http://sso.local/verify
```

**接口设计**：

```
# 1. 授权入口
GET /authorize
Query: app_id, redirect_uri, state

Response: 登录页（未登录时）或 授权确认页（已登录时）


# 2. 登录
POST /api/auth/login
Content-Type: application/json

Request:
{
  "username": "admin",
  "password": "123456",
  "app_id": "vue-demo",           // 来自哪个应用
  "redirect_uri": "http://vue-demo.com/callback",
  "state": "random_state_string"
}

Response (登录成功，重定向):
Location: http://vue-demo.com/callback?code=xxx&state=xxx


# 3. 使用 code 换取 token
POST /api/auth/token
Content-Type: application/json

Request:
{
  "grant_type": "authorization_code",
  "app_id": "vue-demo",
  "app_secret": "app_secret_xxx",
  "code": "authorization_code_xxx"
}

Response:
{
  "code": 200,
  "data": {
    "token": "sso_token_xxx",
    "expires_in": 86400
  }
}


# 4. 验证 token，获取用户信息
POST /api/auth/verify
Content-Type: application/json

Request:
{
  "token": "sso_token_xxx"
}

Response:
{
  "code": 200,
  "data": {
    "user_id": 1,
    "username": "admin",
    "nickname": "管理员",
    "email": "admin@example.com"
  }
}


# 5. 登出
POST /api/auth/logout
Content-Type: application/json

Request:
{
  "token": "sso_token_xxx"
}

Response:
{
  "code": 200,
  "message": "登出成功"
}
```

#### 2.1.4 SSO 客户端 SDK（Node.js）

Client App 后端使用 SDK 验证 Token：

```javascript
// sso-sdk.js
const axios = require('axios')

class SSOSDK {
  constructor(options) {
    this.ssoUrl = options.ssoUrl
    this.appId = options.appId
    this.appSecret = options.appSecret
  }

  // 验证 token，获取用户信息
  async verifyToken(token) {
    const res = await axios.post(`${this.ssoUrl}/api/auth/verify`, {
      token
    })
    if (res.data.code === 200) {
      return res.data.data
    }
    throw new Error('Token 无效')
  }

  // 获取登录跳转地址
  getLoginUrl(redirectUri, state) {
    const params = new URLSearchParams({
      app_id: this.appId,
      redirect_uri: redirectUri,
      state
    })
    return `${this.ssoUrl}/authorize?${params}`
  }
}

module.exports = SSOSDK
```

- 支持记住登录（7 天免登录）
- 统一的错误提示
